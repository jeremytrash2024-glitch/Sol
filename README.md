# Sol, callisthénie au poids du corps

Application d'entraînement au poids du corps : programme de 28 jours, séances guidées avec minuteur, étirements et module grand écart.

Ouvrir : https://jeremytrash2024-glitch.github.io/Sol/

Chaque personne garde sa progression sur son propre téléphone (stockage du navigateur). Rien n'est envoyé ailleurs.
Pour l'installer comme une appli : menu du navigateur, puis « Ajouter à l'écran d'accueil ».
